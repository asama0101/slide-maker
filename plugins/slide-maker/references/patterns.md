# 型と自由設計（案の作り方）

SKILL.md の 3 章から参照する。`assets/components/` の 11 本（表紙・裏表紙・本文の土台・グラフ 6 種・表 2 種）と絵の見本 5 本は**見本**で、案はすべて自由設計（`NN-R1`〜`NN-R3`）。

## 見本の使いどころ

| 内容 | 近い見本 |
|---|---|
| 表紙・裏表紙 | `cover`・`closing` |
| 文だけの説明 | `text` |
| 数値のグラフ | `bar`・`hbar`・`line`・`stacked`・`pie`・`waterfall`（主張に合う種類を選ぶ） |
| 案の比較（評価軸×案） | `options` |
| 対応一覧（対策・課題・リスク） | `actions` |

## 案（R）

全ページ（表紙・裏表紙も）で、ファイルは `slides/NN-R1.html`〜`NN-R3.html`（2〜3 案）。見本をそのままコピーせず、そのページの主張（ヘッドメッセージ）をいちばんよく見せる構成を、`pp-*` の部品（絵 `pp-picture` も使える）で設計する。案どうしは、色ではなく構成と主役の種類を変える。グラフだけは `data-chart` で書く。守ること・考え方は [html-rules.md](html-rules.md) の「自由設計（R）の指針」。

- `data-variant="案の特徴"` を付ける。デザイン違い（`-d2`・`-d3`）は作らない。
- `check` が違反 0 件になること。
- 区切りのページ（`data-layout="divider"`）は本文のレイアウトを使う。題を置くなら本文の題と同じ大きさにし、置かないなら題の規約（`chromeSpec`）は検査されない。
