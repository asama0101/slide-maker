# 見本の一覧（`assets/components/`）

SKILL.md の 3 章から参照する。下の 11 本と絵の見本 5 本は**見本**で、案はすべて自由設計（`NN-R1`〜`NN-R3`。[patterns.md](patterns.md)・[html-rules.md](html-rules.md)の「自由設計（R）の指針」）で、そのページの主張に合わせて組む。グラフの断片（`data-chart`）の書き方は、そのまま使える。各断片の先頭のコメント（用途・差し替える所）を読んでから使う。断片の部品の書き方は [html-rules.md](html-rules.md)。

## 見本

デザイン違い（`-d2`・`-d3`）はない。1 つの型につき断片は 1 本。

| 区分 | 型 | 用途・差し替える所 |
|---|---|---|
| 骨格 | `cover` | 表紙。題名・副題・日付と部署（位置はテンプレートで決まる） |
| 骨格 | `closing` | 裏表紙。結びの一文・要点の再掲・次のステップ |
| 骨格 | `text` | 本文の土台。文だけのページ。見出し＋本文×3 |
| グラフ | `bar` | 縦棒。量の比較。注目する棒だけ強調（`highlight`） |
| グラフ | `hbar` | 横棒。項目名が長い・項目が多い |
| グラフ | `line` | 折れ線。時間の推移。系列は 3 本まで |
| グラフ | `stacked` | 積み上げ棒。内訳の推移。系列は 3 本まで |
| グラフ | `pie` | 円。割合。項目 5 つまで |
| グラフ | `waterfall` | 滝。増減の道筋 |
| 表 | `options` | 案の評価表。評価軸×案、推奨の列だけ強調 |
| 表 | `actions` | 対応一覧。事項・内容・期限・担当・状態（列見出しは差し替えられる） |

グラフの断片は、差し替える所がチャートタイトル・`data-chart`・注釈。表は、行と列の文言。

## ページの共通の構成

本文の部品は、上から次の順に置く。

1. **題**（`data-role="title"`）: 名詞句 20 字以内。ページの主題。判断は書かない。既定 37px・本文色（ヘッドメッセージは 27px）。サイズは変数で決まる（[html-rules.md](html-rules.md)）。
2. **ヘッドメッセージ**（`data-role="lead"`、帯の中）: 判断を言い切る 30〜60 字。原稿の `ヘッドメッセージ`。1 行でも帯の縦中央に置く（`base.css` が `data-part="ヘッドメッセージ"` に当てる）。
3. **チャートタイトル**（数値・単位・凡例・時間軸を持つ型だけ。`data-role="body"`、既定 19px・本文色で本体のすぐ上）: 対象・期間・単位の名詞句。題と同じ名詞は繰り返さない。グラフ・数値や凡例のある表・時間や量を扱う図に置く。文章中心のページ（`text`）や、手順・体制・構造・関係の図には置かず、時点や対象は題か注釈に書く。
4. **本体**: 箱・行・棒のすべてに定量（金額・件数・日数・%）を 1 つ以上書き、本文領域の下端（y 640）まで使う。
5. **注**（`caption`）: 出典・前提・凡例。ページ下端の注釈は既定 16px（`--fs-caption`。下限は 14px）、出典・脚注は既定 14px（`--fs-source`）。1 行に長い文を入れて 2 行に折れるときは、高さを足すか 14px にする。

**判断を求める型**（`options`・`actions`）は最下部にメッセージボックス（パネル地の帯。「論点　〜の可否」1 行）を置く。それ以外の**情報の型**は帯を置かず、注釈の末尾を「→ 含意」の 1 文で締める。

## 絵（型に当てはまらない図。`assets/components/pictures/`）

自由設計でも描きにくい図は、SVG の**絵**（`pp-picture`）で描く。絵は 1 枚の画像として PPTX に貼られ、PowerPoint では直せない（題・ヘッドメッセージ・チャートタイトル・注釈は編集できる文字）。書き方と作法は [picture-craft.md](picture-craft.md)。部品（機器アイコン・矢じり）は `assets/pictures/parts.svg`。見本は 1 枚 1 本。

| 見本 | 内容 |
|---|---|
| `traffic-flow` | 構成図の上に、番号付きの矢印で通信の経路を重ねる。想定外の経路だけ強調色の破線 |
| `network` | NW 構成図。ゾーンの枠・機器のアイコン・直角の配線。新設の機器だけ強調色の破線の枠 |
| `failure` | システムの障害動作。上段＝想定動作、下段＝想定外動作。分かれる点だけ強調色の太枠と警告アイコン |
| `self-intro` | 自己紹介。中央に人物、周りに 4 つの吹き出し。手描き風の線（filter を外せばきちんとした見た目） |
| `annotate` | 画面・写真・既存の図に、番号付きの丸と矢印を重ね、右に番号の凡例。利用者の画像を土台にできる |

見本は「題 → ヘッドメッセージの帯 → チャートタイトル → 絵 → 注」の構成で、注釈の末尾を「→ 含意」で締める。

## 見本の追加

新しい見本を足すときは `assets/components/` に断片を置き、先頭コメントに用途・差し替える所を書き、`check` で違反が 0 件になることを確かめる。この一覧にも足す。
