# slide-maker

稟議書・提案書・障害報告を、PowerPoint で直せる .pptx にする Claude Code プラグイン（Windows 専用）。チャットで素材を渡し、スライドの案を選ぶと、コンサル資料のテイストの資料ができる。

## 機能

- **入力は自由**: テーマ、素材（メモ・文書・データ）、既存の Markdown 原稿のどれでもよい。Claude が、資料全体の結論と論点を書いた設計図と、スライドごとの文章を書いた原稿を作る。
- **案を見比べて選ぶ**: スライドの案を、claude.ai の非公開の Artifact（作成者のみ閲覧可）に並べる。どのページも、Claude が自由に設計した構造の違う 2〜3 案。ページごとに選び、コメントで直してもらい、承認する。
- **PowerPoint で直せる**: 本文は画像にせず、図形・文字・表・ネイティブのグラフで出す。
- **自分のテンプレートに載せられる**: `.potx`・`.pptx` を登録すると、その表紙・本文・裏表紙のレイアウトとヘッダー・フッターの上に作る。
- **型にない図も描ける**: NW 構成図や障害の動作は、`/slide-maker:create` に「図にして」と頼むと、絵にして貼る。絵は画像なので、中身は PowerPoint で直せない。

## 前提条件

| 項目 | 内容 |
|---|---|
| OS | Windows |
| Python | 3.10 以上（`venv` と `ensurepip` 付き）。`python` が PATH にあること（専用の環境の作成とプラグインの起動に使う） |
| Claude Code | 必須（プラグインと Artifact を使える版） |
| ネットワーク | 初回に、Python のライブラリと Chromium（数百 MB）を取得する |
| BIZ UDPゴシック | 推奨。未導入だと、PowerPoint で文字の折り返しがずれることがある |
| frontend-design スキル | 推奨。あると、自由設計の案の構図・余白・強弱を考えるのに使う。なくても動く |
| Microsoft PowerPoint | 最終確認と、作成後の直しに使う |

## 導入方法

Claude Code で、次の 3 つを順に実行する。

```
/plugin marketplace add asama0101/slide-maker
/plugin install slide-maker@slide-maker
/reload-plugins
```

`/` を入力して、候補に `slide-maker:create` が出れば、導入できている。

### ローカルに落として導入する

GitHub から直接導入しないときは、リポジトリを clone し、そのフォルダを配布元として登録する。

```
git clone https://github.com/asama0101/slide-maker.git
```

```
/plugin marketplace add C:\Users\<ユーザー名>\...\slide-maker
/plugin install slide-maker@slide-maker
/reload-plugins
```

導入元は clone したフォルダそのものなので、`git checkout` でブランチを切り替えたり、フォルダを移動・削除したりすると、プラグインが変わる、または動かなくなる。

### 初回の準備

初回の `/slide-maker:create` が、最初に環境を診断する（環境は変えず、項目ごとの OK・NG を出す）。専用の環境がない・足りないときは、Claude が導入してよいかを聞く。承認すると、プラグイン専用のフォルダ（`~/.claude/plugins/data/slide-maker-<マーケットプレイス名>/`）に仮想環境を作り、決まった版のライブラリを入れる。システムの Python には入れないので、ほかのツールに影響しない。Chromium は共有の場所（既定は `%LOCALAPPDATA%\ms-playwright`）に入る。

### 更新

新しい版は [Releases](https://github.com/asama0101/slide-maker/releases) で確認できる。次を実行すると更新される。

```
/plugin marketplace update slide-maker
```

ローカルに落として導入したときは、clone したフォルダで `git pull` を実行してから、上の更新を実行する。

### アンインストール

Claude Code の `/plugin` から行う。

| 項目 | アンインストール後 |
|---|---|
| 専用の環境と登録したテンプレート（`~/.claude/plugins/data/slide-maker-<マーケットプレイス名>/`） | 通常は消える。`SLIDE_MAKER_HOME` を設定していたときは残る |
| 作った成果物（出力先の `<成果物名>.pptx` と `slide-maker-source/`） | 残る |
| 案の選択の Artifact（claude.ai） | 残る。不要なら claude.ai で消す |
| Chromium（ほかのツールと共有する場所） | 残る |
| 確認用の画像（`%TEMP%\slide-maker\`） | 残ることがある |

## 使い方

Claude Code で `/slide-maker:create` を実行するか、「稟議資料を作って」のように頼む。

```
/slide-maker:create 新サーバー導入の稟議資料を作って
```

1. Claude が、入力（ファイルのパスか本文）・成果物の名前・基調色と強調色・フッターの文言・テンプレートの有無を聞く。足りない前提（対象者・目的・枚数・欠けている数字）もまとめて聞く。
2. Claude が、入力（文章・テキスト・PPTX・Excel・PDF）を読んで `input.md` にまとめ、設計図と原稿を書き、全ページで 2〜3 案を作る。図・絵・表・グラフが主役でない案があると、警告として知らせる（止まらない）。人の承認は挟まない。
3. Claude が、案を選ぶページを claude.ai の **非公開の Artifact**（作成者のみ閲覧可）に載せて開く。共有しない限り自分にしか見えない。最初に載せる前に、そのことを 1 回伝える。公開・再公開のたびに、結果で非公開かを確かめ、共有されているときは、非公開に戻すよう頼んで止まる（選択を読まず、PPTX も作らない）。
4. ページごとに案を選び、よければ「承認」を押す。直したい点があれば「このページにコメントする」を押し、入力欄の「Claude に送信」にチェックを入れて送る。終わったら、またはコメントを送ったら、チャットで Claude に知らせる。
5. Claude が選択とコメントを読み、コメントのあったページだけを直して、同じ Artifact に載せ直す（URL は変わらない）。直した内容をコメントに返信し、解決済みにする。直したページを、もう一度承認する。ほかのページの承認は残る。
6. 全ページが承認されると、Claude が PPTX を作る。文字のはみ出しや重なりがあれば、Claude が配置を直して作り直す。
7. Claude が、PPTX の保存先と確認用の画像の場所を報告する。PowerPoint で開いて最終確認する。

できあがる PPTX と元データは、Claude Code を起動したフォルダ（カレントディレクトリ。以下 `<出力先>`）に置かれる。

```
<出力先>/
  <成果物名>.pptx             成果物
  slide-maker-source/
    <成果物名>/               設計図・原稿・スライドの案・テンプレートのコピー
```

同じ名前の PPTX や元データが既にあるときは、上書きするか、別の名前にするかを聞かれる。上書きした PPTX は戻せない。PowerPoint で手直しした PPTX を残したいときは、先に別の場所へコピーする。

### 用語

| 用語 | 意味 |
|---|---|
| 設計図 | 資料全体の結論と論点を書いた文書（`design.md`） |
| 原稿 | スライドごとの文章を書いた文書（`script.md`） |
| 見本 | 表紙・裏表紙・本文の土台・グラフ 6 種（縦棒・横棒・折れ線・積み上げ・円・ウォーターフォール）・表 2 種（案の評価表・対応一覧）の断片。案の参考で、なぞらなくてよい |
| 案 | 全ページ 2〜3 案。Claude が、そのページの主張をいちばんよく見せる構成を、主役の図表の種類まで変えて作る |
| 絵 | SVG で描いて 1 枚の画像として貼る図。中身は PowerPoint で直せない |
| 検査 | PPTX を作るときの自動チェック。エラーがあると PPTX は作られない |

## コマンド一覧

Claude Code で打つコマンドは、次の 3 つ。打たずに、文章で頼んでもよい。

| コマンド | 使う場面 | 渡すもの |
|---|---|---|
| `/slide-maker:create` | 資料を新しく作る | テーマ・素材・原稿 |
| `/slide-maker:doctor` | 環境の診断と、最新版かの確認 | なし |
| `/slide-maker:template` | 自分のテンプレートを登録する・一覧を見る・消す | テンプレートのファイル（`.potx`・`.pptx`） |

### 図だけを作る（`/slide-maker:create`）

- 例: `/slide-maker:create 本番環境のネットワーク構成図を作って`
- 型に当てはまらない図（NW 構成図・トラフィックフロー・障害動作・自己紹介・画面への注釈）は、絵（SVG）にして貼る。図 1 枚だけの依頼は、表紙と絵のページの 2 枚になる。
- 素材が薄いときは、Claude が選択式で質問する。素材にない数字や固有名詞は作らず、「xx」にする。
- 題・ヘッドメッセージ・注釈は文字なので PowerPoint で直せる。絵の中身は直せないので、直すときは描き直す。

### `/slide-maker:template`

- 例: `/slide-maker:template D:\テンプレート\社内標準.potx を登録して`
- 登録名は、省略するとファイル名（拡張子なし）になる。同じ名前があると、置き換えるか、別の名前にするかを聞かれる。
- 16:9（13.33×7.5in）で、題と本文の領域があるレイアウトを持つファイルだけ登録できる。
- 使うレイアウトは、表紙・本文・裏表紙だけ。フォントは変わらない（BIZ UDPゴシック）。配色は、設計図に基調色・強調色を書かなければテンプレートの色に従う。
- 登録を消しても、置き換えても、作成済みの成果物には影響しない（成果物が、作成時にコピーを持つため）。

### Claude が内部で使うコマンド

スキルの手順の中で、Claude が `run.py` 経由で実行する。利用者が打つ必要はない。

| コマンド | 内容 |
|---|---|
| `doctor`・`setup --yes` | 環境の診断（GitHub をマーケットプレイスに登録していれば、最新版かも確認する）と、専用の環境の作成 |
| `init` | 作業フォルダを作る（`--template`・`--footer`・`--force`） |
| `lint-script` | 原稿の書式と、題・ヘッドメッセージの形を調べる |
| `review-page` | 案を選ぶページ（`review.html`）を作る |
| `finalize --choices` | 承認された案を 1 つの HTML にまとめる |
| `check`・`build` | 検査と PPTX の書き出し（`build` は `--footer`・`--out`・`--force`） |
| `clean` | 確認用の画像を消す |
| `template-import`・`template-list`・`template-remove` | テンプレートの登録・一覧・削除 |

## 設定

| 項目 | 内容 |
|---|---|
| 基調色・強調色 | 基調色 1 色と強調色 1〜2 色（`#RRGGBB`）。作成の最初に伝える。なければテンプレートの色、それもなければ Claude が提案する。設計図の `基調色:`・`強調色:` に書かれる。v3.0.0 で、init の色の指定とプリセット配色は廃止 |
| 題・リードの文字 | 既定は題 37px・リード 27px・BIZ UDPゴシック・左寄せ。変えるときは、元データの `rules.json`（`{"title": {"size_px", "align"}, "lead": {…}}`）に書く。`size_px` は theme.css の `--fs-title`・`--fs-lead` に反映され、`align` は検査だけ（断片で指定する）。フォントは BIZ UDPゴシック固定（`font` を書くとエラー） |
| フッター | 左下に入れる文言（コピーライトなど）。作成の最初に伝える |
| テンプレート | 16:9 の `.potx`・`.pptx`。`/slide-maker:template` で登録しておくと、作成時に名前で選べる |
| `SLIDE_MAKER_HOME` | 専用の環境とテンプレートの置き場を指定する環境変数。通常は不要 |

## 検査

PPTX を作るとき（`build`）に、次を調べる。1 件でもあると PPTX は作られず、Claude が配置・サイズを直して作り直す。文言や構成を変えないと直らないときだけ、利用者に確かめる。

| 検査 | rule | 内容 |
|---|---|---|
| 色 | `colorRange`・`colorNeon`・`colorContrast` | 資料全体で、無彩色＋基調 1 色＋強調 1〜2 色の範囲を超えている。蛍光色。文字のコントラストが 4.5 未満 |
| 題・リードの文字 | `chromeSpec` | 題・リードの大きさ・フォント・寄せが規約（`rules.json` で変更可）と違う |
| はみ出し | `overflow`・`outOfSlide`・`pptxBounds` | 文字が枠に収まらない。部品がスライドの外に出ている（`pptxBounds` は書き出した PPTX で調べる） |
| 重なり | `overlap` | 部品どうしが意図せず重なっている |
| 文字の欠け | `textLost` | HTML の書き方のせいで、文字が PPTX に入らない |
| ヘッダー・フッターの領域 | `keepout` | テンプレートのヘッダー・フッターの領域に部品が入っている |
| 文字の小ささ | `fontMin`・`pptxFontMin` | 本文 14pt 未満、注記 10pt 未満（`pptxFontMin` は書き出した PPTX で調べる） |
| 図形の種類 | `shapeKind` | `data-shape` が `rect`・`round`・`ellipse`・`triangle` のどれでもない |

## 制限

- **作成後の直しは PowerPoint で行う。** PowerPoint で直した内容は、プラグインには取り込まれない。構成を大きく変えるときは、最初から作り直す。作り直すと、PowerPoint で直した内容は消える。
- **絵の中身は PowerPoint で直せない。** 絵は画像として貼られる。直すときは描き直す（`/slide-maker:create` で頼む）。
- 確認用の画像は HTML を撮影したもので、PowerPoint の実描画ではない。グラフのプレビューは近似で、軸や数字の書式は実際のグラフと一致しないことがある。
- フォントはプラグインで固定（BIZ UDPゴシック）。色は無彩色＋基調 1 色＋強調 1〜2 色の範囲で、資料全体で数える。題・リード以外の文字の大きさは、下限（本文 14pt・注記 10pt）だけ検査する。

## 困ったとき

### 「実行できる専用の仮想環境がありません」（終了コード 3）

専用の環境に、必要なライブラリと Chromium が決まった版でそろっていない。案内に従って、導入を承認する。

### 「[NG] 仮想環境: 壊れています」

専用の環境を作った元の Python が、削除または移動されている。導入を承認すると、環境が作り直される。

### 「[NG] 作成元の Python」

`python` コマンドの Python が、3.10 未満、または `venv`・`ensurepip` を使えない。Python 3.10 以上（`venv` と `ensurepip` 付き）を入れ直し、そちらが `python` になるようにして、もう一度実行する。

### 「既に存在します」（終了コード 4）

出力先に同じ名前の PPTX がある（PowerPoint で手直ししたものかもしれない）。残したいなら、先に別の場所へコピーする。そのうえで、上書きするか、別の名前で出力するかを選ぶ。テンプレートの登録で終了コード 4 が出たときは、同じ登録名がある。

### 案を選ぶページに「保存先（db）に接続できません」と出る

ページが保存先を付けずに公開されている。Claude に、同じページを保存先付きで公開し直すよう頼む。

### 送ったコメントを、Claude が読まない・返信しない

コメントを送るときに、入力欄の「Claude に送信」にチェックを入れていなかった。チェックのないコメントは Claude に届かない。もう一度「このページにコメントする」から、チェックを入れて送る。前のコメントが要らなければ、自分で解決済みにする。

### 案を選ぶページに「この環境ではコメントを開けません」と出る

ページがコメントの機能を付けずに公開されている。Claude に、同じページをコメントの機能付きで公開し直すよう頼む。

### 「案の選択ページが、自分以外にも閲覧できる設定になっています」と Claude が止まる

公開の結果に `readable by only you` がなかった（共有されている、または状態を読み取れなかった）。claude.ai のページの Share メニューで非公開に戻し、Claude に「戻した」と伝える。共有の設定は Claude には変えられない。共有されている間に他の人が選択を書き換えた可能性があるので、Claude が読んだ選択を確かめる。

### そのほか

| 症状 | 対処 |
|---|---|
| 文字の折り返しが、PowerPoint とずれる | BIZ UDPゴシックを導入する |
| 絵の中の文字を直したい | `/slide-maker:create` で絵を描き直す |
